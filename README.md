# 🎬 Movie Battle

Movie Battle is a responsive web application that allows users to compare two movies and see which one "wins" based on various data like ratings, and box office numbers.

## 🚀 Features

- Search for any two movies
- Pulls movie data from the OMDb API
- Displays a side-by-side comparison
- Highlights the "winning" movie in each category

## 🛠️ Built With

- HTML
- CSS
- React
- OMDb API (http://www.omdbapi.com/)
